# GAS, Animation and UI-System based on UE5 LyraStarterGame

## Overview
Online multiplayer gameplay system with different NPC characters, AI, GAS, EQS, UI and layered animation system.

## Tech Stack
- C++
- Unreal 5.4

## Contribution
- hybrid gameplay architecture with C++ and Blueprint
- AI system with controller, behavior tree, navigation, perspection, EQS for different NPC enemies(e.g. melee with combo and VFX/SFX, ranged, teleporting etc.)
- Gameplay Ability System (GAS) for modular weapons and abilities
- state-driven animation systems for complex locomotion (e.g.swimming, climbing)
- inventory system including UI development using UMG and Slate
