# GAS, Animation and UI-System based on UE5 LyraStarterGame

## Overview
Developed a multiplayer gameplay system based on Unreal Engine 5 Lyra Starter Game, focusing on scalable architecture, AI behavior, and modular gameplay features.

The project integrates multiple systems including AI, abilities, animation, and UI into a unified real-time gameplay framework.

## Tech Stack
- C++
- Unreal Engine 5.4
- Gameplay Ability System (GAS)
- Behavior Tree / EQS
- UMG / Slate

## My Contributions

- Designed a hybrid gameplay architecture using C++ and Blueprint for performance and rapid iteration

- Implemented AI systems including controllers, behavior trees, navigation, perception, and EQS for multiple enemy types (melee, ranged, teleporting)

- Built a modular Gameplay Ability System (GAS) for weapons and abilities, supporting extensible gameplay logic

- Developed state-driven animation systems for complex locomotion (e.g. swimming, climbing)

- Implemented an inventory system with UI using UMG and Slate

## Technical Highlights

- Modular system design for scalable gameplay development

- Integration of AI, animation, UI, and gameplay systems in a multiplayer environment

- Clear separation of core logic (C++) and high-level behavior (Blueprint)
